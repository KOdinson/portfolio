Box 1 · Purpose

Volume Check puts every submission rule next to your own number and tells you the gap. The send button stays shut until nothing blocks it.

Box 2 · Demonstration

Live prototype with sample rules. Trim the pages, upload the report, sign the form, and the gate opens.

Box 3 · Every line reads the same way

A checklist records that someone looked. This shows what they saw, and ends with an instruction that has a number in it.

Box 4 · Status (mark one)
  • ■ Blocks sendingThings that get a proposal rejected. Red appears nowhere else, so it still means something.
  • ▲ Fix if you canThings that cause delay, such as a form that is filled in and not signed.
  • ✓ ReadyEverything else. The list sorts itself so the top line is always the next thing to do.
Box 5 · Declaration

A tool that states a rule wrongly is worse than no tool.

Every rule cites the section it came from, so the original wording can be checked. Turning a new set of instructions into rules needs a person to confirm it, every time. The rules in this prototype are samples, not any real solicitation.
