The button explains itself

While anything blocks, it reads "Cannot send yet" and the panel beside it lists exactly what stands in the way.

Worst news first

Blockers, then warnings, then everything that is fine. The top of the list is always the next thing to do.

Every rule cites its source

Each rule ends with the section it came from, so you can check the original wording when it matters.

The honest limit

A tool that states a rule wrongly is worse than no tool.

The hard part of a real version is turning a new set of instructions into rules correctly. That step needs a person to confirm it, every time. The rules in this prototype are samples, not any real solicitation.
